First divergence attribution:
ITEMSTACK_TOOLTIP_GENERATION means the generated list already differs before event creation.
<concrete class.method>.AFTER identifies the first observed changed handler-output boundary.
EVENTBUS_DISPATCH_BEFORE:<handler>.BEFORE identifies an unobserved interval inside dispatch.
EVENTBUS_DISPATCH_UNTRACED_INTERVAL covers a change first observed when post returns.
These labels describe measured boundaries, not an invented ultimate source mod; relay handlers
may delegate internally. Item-generation attribution includes item code/mixins inside generation.
